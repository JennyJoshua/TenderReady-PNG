# Contributing

1. Change one thing at a time and describe it in the pull request.
2. Run `actionlint` and `shellcheck scripts/*.sh` before committing (they run on any computer; not required from a phone).
3. Never add secrets, keystores or `.env` files.
4. Keep third-party actions pinned to full commit SHAs with a version comment.
5. Update `CHANGELOG.md` and, for design choices, `DECISIONS.md`.
6. Do not claim support for something that has not been run.
